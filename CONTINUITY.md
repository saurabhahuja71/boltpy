# Boltpy continuity

- Summary: Boltpy Phase 1, Phase 2, Phase 3, Phase 4, and Phase 5 are complete; this checkout includes multi-provider config, plan mode, todos, options picker, HTTP tool, theme variables, and scoped permanent permissions.
- Architecture: the existing Agent → ToolRegistry → PermissionManager → TUI adapter remains intact. Providers are now behind a `Provider` abstraction with `OpenAICompatibleProvider` and `OllamaProvider`, selected via `Settings.provider` and `build_provider()`. Local shell, system-SSH, and `http_request` tools validate safety before asynchronous permission checks and return structured results. `present_options` is routed through `Agent.options_handler` so the TUI can render the picker while headless mode falls back to the first option.
- New user features: `/model` selects configured models (plus discovered Ollama names) from an inline keyboard/mouse OptionList; `/todo` toggles the live todo side panel driven by `add_todo`/`complete_todo`/`update_todo`/`list_todos`; `/mode plan` blocks capability-guarded tools so the agent proposes a plan; the agent can call `present_options` to show a numbered picker with a typed-answer input; `/permissions` lists exact persistent grants and `/permissions remove "command"` removes one. Permanent approvals are stored in `~/.config/boltpy/permissions.toml`, with SSH scopes including host, user, port, and command.
- TUI behavior: the layout is a single `ConversationLog` (VerticalScroll) transcript in the left/center with the collapsible `TodoPanel` sidebar on the right, status bar and input at the bottom. All assistant output, streaming text, and tool cards render into that one transcript — there is no separate streaming area. Dark/light themes are registered Textual themes with `$` CSS variables; the active theme comes from config. The `CWD: <path>` line sits at the top. Interactive mouse mode (widget clicks and scrolling) is the default; `/mouse select` enables native terminal selection, and `/mouse interactive` returns to widget mode. Prompts typed while a task is running are queued (`/queue` lists them) and run in order; Ctrl+C cancels the current task and clears the queue.
- Config: `boltpy.toml`/`~/.config/boltpy/config.toml` now support `provider`, `model`, `models`, `api_key`, `base_url`, `permission_mode` (ask|allow|plan), and `theme`; env vars `OPENAI_PROVIDER`/`BOLTPY_PROVIDER` and `BOLTPY_THEME` were added. CLI `ask`/`exec` accept `--model` and `--provider`.
- Validation: `uv run --dev pytest -q` passes 45 tests; compileall, CLI help, headless-import, and `git diff --check` pass.
- Release: package version is 1.0.2; GitHub `v1.0.0`, `v1.0.1`, and `v1.0.2` are published; `v1.0.2` is https://github.com/saurabhahuja71/boltpy/releases/tag/v1.0.2.
